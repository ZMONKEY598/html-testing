This site primarily uses JSON data to write character information to a local disk.

To create a character, select "start from scratch" or "generate random character"

In-progress data is saved in web browser temporarily. The tool can export either a txt file, the JSON output, or a fillable PDF file (without character formatting, sue me).

A character must be created at level one before leveling up to a maximum of 5. To do this, navigate to home page (upper right button) and open the character library. You can select a folder that contains your exported JSON files, or open/edit from the list of browser-saved characters. One a characted is selected, it will display at the top. You can then hit level up to begin the leveling process.
